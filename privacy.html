Luka プライバシーポリシー

「Luka」は、DareDan Circle の運営者が自分専用に使う、個人用の音声アシスタントです。運営者本人以外は利用しません。

取得する情報

  • YouTube Analytics API・YouTube Data API：運営者自身のYouTubeチャンネルの再生回数・推定収益・コメントなどの統計情報（読み取りのみ）
  • AdSense Management API：運営者自身のAdSenseアカウントの残高・支払い履歴（読み取りのみ）

情報の使い方

取得した情報は、運営者のパソコンの中だけで、運営者への回答（数字の読み上げや分析）のために使います。第三者への提供・販売・広告への利用はしません。

情報の保存

ログインの情報（認証トークン）は運営者のパソコン内にのみ保存し、外部のサーバーには保存しません。運営者はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から Luka のアクセスを取り消せます。

Google API サービスの利用について

Luka による Google API から受け取った情報の使用と他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。
